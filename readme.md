# Международный васюкинский турнир

Адаптивный одностраничный лендинг для вымышленного шахматного турнира в Васюках. Проект сделан по критериям на чистых HTML, CSS и JavaScript без сторонних библиотек, фреймворков и сборщика.

## Что сделано

- Сверстана адаптивная главная страница для мобильных, десктопных и широких экранов.
- Реализован стартовый экран с якорными кнопками и плавной прокруткой.
- Добавлена бесшовная бегущая строка на всю ширину экрана.
- Собран блок с информацией о турнире и визуальными материалами из папки `img/`.
- Реализован блок «Этапы преображения Васюков»: сетка на десктопе и ручная незакольцованная карусель на экранах меньше 1366px.
- Реализована карусель «Участники турнира»: автопрокрутка каждые 4 секунды, зацикливание, пауза при наведении на карточку.
- Настроены состояния интерактивных элементов: hover, disabled и плавные переходы.
- Добавлены локальные шрифты, фавиконки и базовая доступность.

## Технологии

- HTML5
- CSS3
- Vanilla JavaScript ES6+

## Как запустить

Установка зависимостей не нужна. Запустите локальный сервер из корня проекта:

```bash
python -m http.server 8000
```

После запуска откройте в браузере:

```text
http://localhost:8000
```

## Структура

```text
index.html        # разметка страницы
styles/index.css  # стили и адаптив
scripts/index.js  # интерактивные элементы
img/              # изображения и иконки
fonts/            # локальные шрифты

```
